# Contributing

PALMS was developed as a final year research project at BIUST. Code contributions and experiment results are welcome.

## Ways to Contribute

- **Bug reports** — open an issue with steps to reproduce
- **Experiment results** — tried different hyperparameters or scenarios? Share findings in an issue
- **Code improvements** — open a PR with a clear description of the change

## Running the Code

See the README for environment setup and training instructions.
Always run scripts from the **repo root**: `python src/train_mappo.py`

## Questions

Open an issue or reach out via [GitHub](https://github.com/geranimoekia).
